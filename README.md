### What I work on

- **AI accelerators.** Efficient hardware for neural network inference, including spiking and reservoir computing.
- **Analog and mixed-signal IC design.** Mostly Cadence Virtuoso and Spectre.
- **Chiplets and physical design.** Keeping track of where chiplet tech is heading.
- **Small tools** for problems I run into, usually in Python.

I also review for the IEEE Computer Society Annual Symposium on VLSI (ISVLSI).
